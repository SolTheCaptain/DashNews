# Дашборд

Страница с карточками (матчи, таблицы и т. д.). Данные собирает `collect.py` по расписанию,
страница `index.html` просто показывает `data.json`.

## Как это устроено

- `config.json` — список блоков (что показывать и откуда). Главный файл для правок.
- `collect.py` — сборщик: для каждого блока вызывает обработчик по полю `type`.
- `index.html` — страница.
- `.github/workflows/update.yml` — расписание: раз в час и в 11:40 по Москве, плюс при любом изменении файлов.

## Добавить блок

В `config.json` в список `cards` добавь объект:

```json
{ "id": "barca", "title": "Барселона — ближайший матч", "type": "team_next", "team": "Barcelona", "country": "Spain" }
```

Типы блоков сейчас:

| type | что делает | параметры |
|---|---|---|
| `team_next` | ближайший матч команды (TheSportsDB) | `team` (англ. название), `country` |
| `teams_next` | ближайший матч каждой команды из `teams` (эмблемы, места в скобках); у команды можно задать `round: {league_id}` — под матчем раскрывается список всех матчей ближайшего тура чемпионата | `teams` (`name`, `label`, `emblem`, `country`, `id`, `round`) |
| `fd_table` | таблица турнира (football-data.org) | `comp` (CL, PD, PL, BL1, SA, FL1…), `cutoffs` |
| `fd_next` | матчи турнира на N дней вперёд (football-data.org) | `comp`, `days`, `first_day_only` |
| `slam_russians` | ближайший шлем: невылетевшие игроки из топ-N, родившиеся в нужной стране, и их матч (ESPN) | `slams`, `top`, `born_in` |
| `steam_upcoming` | топ-N ожидаемых игр до конца года из «Популярных ожидаемых» Steam | `count`, `scan` |
| `mtg_roadmap` | основные сеты Magic (core, expansion) до конца года, без даты — TBA (Scryfall) | `count` (сколько ближайших показать; без него — до конца года), `extra` (названия сетов без даты вручную), `types` (по умолчанию core, expansion) |
| `mtg_bans` | дата следующего анонса банов (из последнего анонса Wizards) (раз в `refresh_days` дней; запасной вариант — `manual` в config.json) |
| `quotes` | курсы ЦБ к рублю и BTC/USD (cbr-xml-daily.ru, CoinGecko) | `fiat` (коды валют ЦБ, по умолчанию USD, EUR) |
| `sheet_tasks` | задачи из Google Таблицы (Дата, Время, Контакт, Описание); id таблицы в секрете `TASKS_SHEET_ID` | `days` (окно в днях, по умолчанию 10), `gid` (номер листа, по умолчанию 0) |

## Убрать блок

Добавь в его объект `"enabled": false` (или удали объект целиком).

## Если блок показывает ошибку

На странице под блоком будет написано, что не получилось, и показаны последние удачные данные.
Подробности в GitHub: вкладка Actions → последний запуск → шаг «Собрать данные».

## Ключи

Лежат в секретах репозитория (Settings → Secrets and variables → Actions):
`FOOTBALL_DATA_KEY` — ключ football-data.org, `TASKS_SHEET_ID` — id таблицы с задачами. В файлы ключи не записываются.
